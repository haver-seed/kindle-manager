# Kindle Manager v0.2.0

这是一次完整的可靠性升级和视觉重设计。

## 新界面

- 全新的森林绿与暖白阅读主题
- 重做侧栏、书架卡片、表格、按钮、页面标题与空状态
- 统一应用图标和视觉层级
- 扫描与转换迁移到后台任务，长操作不再冻结窗口

## 数据安全

- 删除书籍改为移动到 `.kindle-manager-trash`，支持手动恢复
- 删除路径严格限制在 Kindle 根目录内
- 修改 `My Clippings.txt` 前自动创建备份并原子写入
- 导入书籍使用临时文件落盘，避免设备断开留下半个文件
- 导出文件自动避让重名，不覆盖已有内容

## 兼容性与修复

- 扫描范围扩展到整个 `documents`，兼容更多目录布局
- 增加 TXT 扫描支持，并阻止通过 USB 错误导入 EPUB
- 修复中文上午/下午时间解析和词库本地时区
- 修复本地转换源残留、设备断开后显示旧数据等问题
- 移除不可靠的内置 MOBI 二进制提取，格式转换统一使用 Calibre
- 修复 PyInstaller 错误打包 Conda ICU 导致的 QtWidgets 启动失败

## 下载与要求

- 下载下方的 `KindleManager.exe`，无需安装即可运行
- 支持 Windows 10 / 11
- 格式转换功能需要另行安装 Calibre
- 本项目不会绕过 DRM

本版本已通过 13 项自动化测试、Ruff 静态检查和 Windows EXE 主窗口级冒烟测试。
